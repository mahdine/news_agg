۲۶ مارس ۲۰۲۵

من یک نوع محتوای جدید به وبلاگم اضافه کرده‌ام: یادداشت‌ها (notes). این نوع محتوا به دسته‌بندی‌های موجود من یعنی ورودی‌ها (entries)، نشان‌گذاری‌ها (bookmarks) و نقل‌قول‌ها (quotations) اضافه می‌شود.

یک یادداشت، تا حدی شبیه به یک نشان‌گذاری بدون لینک است. این یادداشت‌ها برای نوشته‌های کوتاه هستند؛ افکار یا تصاویری که نیازی به یک ورودی کامل با عنوان ندارند. از همان نوع مطالبی که قبلاً در Twitter منتشر می‌کردم، اما حس می‌کنم برای بازنشر در شبکه‌های اجتماعی متعدد (مثلاً Mastodon و Bluesky) مناسب نیستند.

من تا حدی از افکار کوتاه، یادداشت‌ها، لینک‌ها و تأملات Molly White الهام گرفتم.

مدتی بود که به این موضوع فکر می‌کردم، اما حجم کاری که برای تغییر تمام بخش‌های سایتم جهت پشتیبانی از سه نوع محتوای مختلف لازم بود، دلهره‌آور به نظر می‌رسید. سپس همین امشب تصمیم گرفتم کد منبع وبلاگم را (با استفاده از files-to-prompt و LLM) از طریق مدل جدید Gemini 2.5 Pro اجرا کنم:

```bash

files-to-prompt . -e py -c | \

llm -m gemini-2.5-pro-exp-03-25 -s \

'I want to add a new type of content called a Note,

similar to quotation and bookmark and entry but it

only has a markdown text body. Output all of the

code I need to add for that feature and tell me

which files to add the code to.'

```

مدل Gemini یک برنامه ۱۳ مرحله‌ای دقیق به من داد که تمام تغییرات خسته‌کننده‌ای را که از فکر کردن به آن‌ها طفره می‌رفتم، پوشش می‌داد!

کد مربوطه در این PR قرار دارد که ۱۸ فایل مختلف را تحت تأثیر قرار داد. کل این پروژه از ابتدا تا انتها حدود ۴۵ دقیقه زمان برد.

(من از Claude برای ایده‌پردازی جهت انتخاب نام این قابلیت استفاده کردم؛ از او خواستم اسم‌های احتمالی را پیشنهاد دهد و سپس آن‌ها را «از کم‌ادعاترین تا پرادعاترین رتبه‌بندی کند» و در نهایت «notes» به عنوان گزینه برتر انتخاب شد.)

این متن اکنون برای یک یادداشت بیش از حد طولانی شده و در واقع باید به یک ورودی (entry) ارتقا یابد، اما من باید اولین یادداشت را منتشر کنم تا مطمئن شوم همه چیز همان‌طور که باید، کار می‌کند.
