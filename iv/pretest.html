آشنایی با Python

E2E · 2026-11-21

یادگیری Python چه برای کسانی که برای اولین بار برنامه‌نویسی می‌کنند و چه برای کسانی که با زبان‌های دیگر تجربه دارند، آسان است. صفحات زیر گام نخست مفیدی برای شروع مسیر شما در نوشتن برنامه با Python هستند!

جامعه کاربری این زبان، کنفرانس‌ها و گردهمایی‌هایی برگزار می‌کند، در زمینه کدنویسی همکاری دارد و کارهای بسیار دیگری انجام می‌دهد. مستندات Python در طول این مسیر به شما کمک خواهند کرد و لیست‌های پستی شما را در ارتباط نگه می‌دارند.

Python Package Index یا همان PyPI، میزبان هزاران ماژول شخص‌ثالث برای Python است. هم کتابخانه استاندارد Python و هم ماژول‌هایی که توسط جامعه کاربری ارائه شده‌اند، امکانات بی‌پایانی را فراهم می‌کنند.

Python تحت یک مجوز متن‌بازِ مورد تایید OSI توسعه یافته است که استفاده و توزیع آن را، حتی برای مقاصد تجاری، آزاد می‌سازد. مجوز Python توسط Python Software Foundation مدیریت می‌شود.

ماموریت Python Software Foundation ترویج، محافظت و پیشبرد زبان برنامه‌نویسی Python و همچنین حمایت و تسهیل رشد یک جامعه متنوع و بین‌المللی از برنامه‌نویسان Python است. بیشتر بدانید
