افزونه‌های PostgreSQL با استفاده از Go

Hacker News Feed · 2026-11-22

پروژه gopgext با استفاده از TinyGo، افزونه‌های PostgreSQL را از کدهای ساده Go می‌سازد. کافی است یک تابع را با دستور `//gopgext:function` نشان‌گذاری کنید تا به یک تابع SQL تبدیل شود: gopgext کدهای رابط C، اسکریپت نصب و فایل کنترل را می‌نویسد.

فقط Go

یک پروژه شامل فایل‌های ساده Go است. کتابخانه استاندارد به خوبی کار می‌کند: fmt، regexp، encoding/json، crypto/*، maps، generics، iterators و defer/recover.

نگاشت انواع داده به SQL

رشته‌ها، اعداد، آرایه‌ها، مقادیر NULL، مجموعه‌ها، سطرها، timestamps، UUIDها و JSON به انواع داده‌های SQL نگاشت می‌شوند. شما می‌توانید انواع داده‌های اختصاصی و انواع ترکیبی (composite types) خود را در Go تعریف کنید.

پرس‌وجوها و خطاها

اجرای SQL از طریق SPI، بازگرداندن خطاها با کدهای SQLSTATE، ثبت وقایع (log)، خواندن تنظیمات و حفظ پاسخ‌گویی به لغو پرس‌وجوها امکان‌پذیر است.

فراتر از توابع

نوشتن تریگرها، توابع تجمعی (aggregates)، کلاس‌های عملگر GiST، GIN، SP-GiST و BRIN، روش‌های دسترسی به ایندکس، نگاشت‌گرهای داده‌های خارجی (foreign data wrappers) و قلاب‌های پرس‌وجو (query hooks).

اثبات‌شده در contrib

پورت‌های ماژول‌های contrib در PostgreSQL (مانند pgcrypto، hstore، pg_stat_statements، cube و غیره) تست‌های رگرسیون اصلی (upstream) را با موفقیت پشت سر می‌گذارند.

هم‌زیستی ایمن

چندین افزونه Go می‌توانند در یک بک‌اند بارگذاری شوند. خطاهای PostgreSQL هرگز از طریق فریم‌های Go منتشر نمی‌شوند و نتایج در حافظه PostgreSQL کپی می‌شوند.

Hello, world

```go

package main

import (

"strings"

"gopgext/pg"

)

// Hello یک خوش‌آمدگویی برای نام بازمی‌گرداند.

//

//gopgext:function immutable parallel=safe

func Hello(name string) string {

return "Hello, " + name + "!"

}

// Shout رشته s را به حروف بزرگ تبدیل می‌کند. رشته خالی باعث بروز خطا می‌شود.

//

//gopgext:function immutable parallel=safe

func Shout(s string) (string, error) {

if s == "" {

return "", pg.Errorf(pg.CodeInvalidParameterValue, "nothing to shout")

}

return strings.ToUpper(s) + "!", nil

}

func main() {} // یک بار در هر بک‌اند، هنگام بارگذاری کتابخانه توسط PostgreSQL اجرا می‌شود

```

```bash

gopgext init hello # ایجاد hello/go.mod و hello/main.go

gopgext install hello # ساخت hello.so، hello.control، hello--1.0.sql و نصب آن‌ها

psql -c 'CREATE EXTENSION hello' -c "SELECT hello('world')"

# hello

# ---------------

# Hello, world!

```

آموزش موجود، مراحل را گام‌به‌گام توضیح می‌دهد.

یک پروژه هم‌خانواده

پروژه gopgext از همان رویکرد gokm استفاده می‌کند که ماژول‌های هسته لینوکس را با Go می‌سازد: یک هدف (target) سفارشی در TinyGo و لایه زمان اجرا برای میزبان، یک زمان اجرای C که توسط سیستم ساخت خودِ میزبان (در اینجا PGXS و در آنجا kbuild) کامپایل می‌شود، و کدهای رابط (glue) تولیدشده.
