# C# بدون هیچ پیش‌نیاز

Hacker News Feed · 2026-11-22

یک انشعاب (Fork) از bflat، زبان C# را مستقیماً به یک برنامه بومی (Native) کوچک کامپایل می‌کند: بدون .NET runtime، بدون Garbage Collector و بدون نیاز به نصب هیچ‌چیز در مقصد اجرا.

شما نحو (Syntax)، بررسی نوع (Type checking) و Genericهای C# را حفظ می‌کنید. حافظه از طریق Arenaها تأمین می‌شود که می‌توانید همه آن‌ها را یک‌جا آزاد کنید، و یک کتابخانه کوچک، رشته‌ها، مجموعه‌ها، ورودی و خروجی را با همین شرایط در اختیار شما قرار می‌دهد. همان سورس‌کد روی Linux، macOS و Windows، روی WebAssembly و روی DOS در یک پردازنده 386 اجرا می‌شود.

```csharp

// خواندن در یک بافر پشته: هیچ‌چیز به ازای هر پاسخ تخصیص نمی‌یابد.

Span<char> buffer = stackalloc char[32];

Out.Write($"Q{i}: {a} + {b} = ");

int length = In.ReadLine(buffer);

// تا پایان نگه داشته می‌شود، بنابراین به یک Arena می‌رود.

mistakes.Add(Str.Format(keep,

$"{a} + {b} = {a + b}, not {value}"));

```

### زبان باقی می‌ماند، Runtime می‌رود

کامپایلر همچنان تمام مواردی را که در .NET بررسی می‌کند، چک می‌کند. آنچه حذف شده، کارهایی است که یک Runtime در حین اجرای برنامه شما انجام می‌دهد.

**شما حفظ می‌کنید:**

- **C# 15:** یونیون‌ها (Unions)، اعضای افزونه (Extension members) و قوانین جدید ایمنی حافظه.

- **Genericهای واقعی:** یک کپی تخصصی برای هر نوع، و اعضای استاتیک انتزاعی (Static abstract members).

- **اینترفیس‌ها و متدهای مجازی:** متدهای پیش‌فرض اینترفیس، Castها، is و as.

- **رکوردها، تاپل‌ها، انواع ناشناس:** برابری مقداری (Value equality)، with و متد تولیدشده ToString.

- **لامبداها و کوئری‌ها:** Where، Select و GroupBy، از یک کتابخانه کوچک به جای LINQ.

- **رشته‌ها:** Parallel.For که یک حلقه را روی تمام هسته‌ها اجرا می‌کند.

**شما صرف‌نظر می‌کنید از:**

- **Garbage collector:** آرناها (Arenas) حافظه خود را هر زمان که شما بخواهید، یک‌جا آزاد می‌کنند.

- **.NET runtime:** برنامه Hello world روی ویندوز ۱۱ کیلوبایت و روی لینوکس ۴۰ کیلوبایت است، بدون نیاز به نصب هیچ‌چیز.

- **Catch کردن استثناها:** throw برنامه را خاتمه می‌دهد. خطاها را به صورت یونیون برگردانید.

- **Reflection و async:** یک نوع داده قابل مقایسه است، اما نامی ندارد.

### یک برنامه، پنج ماشین

نمونه hello-world، بدون تغییر، برای هر هدف ساخته شده است. هر بیلد توسط همان مجموعه تست بررسی می‌شود که خروجی یکسانی را در همه جا می‌طلبد.

```bash

$ ./build.sh Minimal

$ ./run.sh Minimal

Hello from zero-mode!

$ wc -c bin/Minimal

39848 bin/Minimal

```

**Linux, x64 یا arm64**

یک برنامه بومی که فقط به کتابخانه C نیاز دارد. در macOS، این برنامه در یک کانتینر ساخته و اجرا می‌شود.

```bash

$ ./build.sh --mac Minimal

$ bin/mac/Minimal

Hello from zero-mode!

$ wc -c bin/mac/Minimal

64728 bin/mac/Minimal

```

**macOS روی Apple Silicon**

یک برنامه بومی مک: bflat آن را کامپایل می‌کند و clang خودِ مک آن را لینک می‌کند. بدون نیاز به کانتینر برای اجرا.

```bash

$ ./build.sh --win Minimal

$ ./run.sh --win Minimal

Hello from zero-mode!

$ wc -c bin/win/Minimal.exe

10752 bin/win/Minimal.exe

```

**Windows x64**

یک برنامه کنسولی بر پایه کتابخانه C ویندوز، که از لینوکس یا macOS ساخته شده است. تست‌شده تحت Wine.

```bash

$ ./build.sh --wasm Minimal

$ ./run.sh --wasm Minimal

Hello from zero-mode!

$ wc -c bin/wasm/Minimal.wasm

15833 bin/wasm/Minimal.wasm

```

**WebAssembly**

یک ماژول WASI، از طریق NativeAOT-LLVM. اجرا تحت wasmtime.

```text

C:\>D:

D:\>PROGRAM

Hello from zero-mode!

D:\>DIR PROGRAM.EXE

PROGRAM EXE 16,384

D:\>

```

**DOS روی یک 386**

همان بیت‌کد که برای 386 کامپایل شده و توسط HX DOS extender اجرا می‌شود. تست‌شده روی مدل i386 در Bochs.

### چه چیزی متفاوت است و چه چیزی به دست می‌آورید

بدون Runtime، چند مورد متفاوت عمل می‌کنند. هر کدام صفحه‌ای دارند که توضیح می‌دهد چرا و به جای آن چه باید کرد.

- **حافظه برای آزاد کردن در اختیار شماست:** Garbage collector وجود ندارد، بنابراین Memory بدون Garbage collector هرگز با new آزاد نمی‌شود. آرناها (Arenas) حافظه را تخصیص می‌دهند و همه را یک‌جا، در پایان طول عمرشان آزاد می‌کنند.

- **متن بدون رشته‌های دورریختنی:** رشته‌ها بدون Garbage collector؛ متد Out.Line($"...") مستقیماً در بافر خروجی فرمت می‌شود و In.ReadLine در یک Span می‌خواند. رشته‌هایی که باید باقی بمانند در یک Arena قرار می‌گیرند.

- **مجموعه‌هایی که در آرناها زندگی می‌کنند:** انتخاب یک مجموعه؛ List، Dict و نسخه‌های آن‌ها برای ارجاعات و کلیدهای رشته‌ای، همگی هندل‌هایی به یک Arena هستند.

- **C# 15، با قوانین ایمنی فعال:** هر برنامه تحت قوانین به‌روز شده ایمنی حافظه کامپایل می‌شود: ایجاد یک اشاره‌گر (Pointer) ایمن است، خواندن از طریق آن علامت‌گذاری و توضیح داده می‌شود.
