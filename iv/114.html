بهینه‌سازی استنتاج و استقرار مدل‌های هوش مصنوعی با OpenVINO™

GitHub Trending · 2026-11-22

- بهینه‌سازی استنتاج (Inference Optimization): عملکرد یادگیری عمیق را در بینایی ماشین، تشخیص خودکار گفتار، هوش مصنوعی مولد، پردازش زبان طبیعی با مدل‌های زبانی بزرگ و کوچک، و بسیاری از وظایف رایج دیگر افزایش دهید.

- پشتیبانی منعطف از مدل‌ها: از مدل‌های آموزش‌دیده با فریم‌ورک‌های محبوبی مانند PyTorch، TensorFlow، ONNX، Keras، PaddlePaddle و JAX/Flax استفاده کنید. با استفاده از Optimum Intel، مدل‌های ساخته‌شده با transformers و diffusers را مستقیماً از Hugging Face Hub ادغام کنید. مدل‌ها را بدون نیاز به فریم‌ورک‌های اصلی، تبدیل و مستقر کنید.

- سازگاری گسترده با پلتفرم‌ها: نیازهای منابع را کاهش دهید و به‌طور کارآمد بر روی طیف وسیعی از پلتفرم‌ها از لبه (edge) تا ابر (cloud) مستقر کنید. OpenVINO™ از استنتاج روی CPU (x86, ARM)، GPU (پردازنده‌های گرافیکی مجتمع و مجزای Intel) و شتاب‌دهنده‌های هوش مصنوعی (Intel NPU) پشتیبانی می‌کند.

- جامعه و اکوسیستم: به جامعه‌ای فعال بپیوندید که در ارتقای عملکرد یادگیری عمیق در حوزه‌های مختلف مشارکت دارند.

برای دسترسی سریع، «برگه تقلب» (Cheat Sheet) و «ویژگی‌های کلیدی» OpenVINO را بررسی کنید.

توزیع دلخواه خود از OpenVINO را دریافت کنید یا برای نصب سریع از این دستور استفاده کنید:

pip install -U openvino

پس از نصب، می‌توانید با اجرای دستورات زیر از نصب صحیح OpenVINO اطمینان حاصل کنید:

import openvino as ov

print(ov.__version__)

برای اطلاعات دقیق، نیازمندی‌های سیستم و دستگاه‌های پشتیبانی‌شده را بررسی کنید.

مثال «شروع سریع» (Quickstart) OpenVINO، شما را با اصول اولیه استقرار اولین مدل‌تان آشنا می‌کند.

یاد بگیرید چگونه مدل‌های محبوب را با استفاده از نوت‌بوک‌های OpenVINO بهینه‌سازی و مستقر کنید 📚:

نمونه‌های بیشتر را در بخش نمونه‌های OpenVINO (Python & C++) و نوت‌بوک‌ها (Python) کشف کنید.

در اینجا نمونه کدهای ساده‌ای برای اجرای استنتاج مدل‌های PyTorch و TensorFlow با استفاده از OpenVINO آورده شده است:

مدل PyTorch

import openvino as ov

import torch

import torchvision

# بارگذاری مدل PyTorch در حافظه

model = torch.hub.load("pytorch/vision", "shufflenet_v2_x1_0", weights="DEFAULT")

# تبدیل مدل به مدل OpenVINO

example = torch.randn(1, 3, 224, 224)

ov_model = ov.convert_model(model, example_input=(example,))

# کامپایل مدل برای دستگاه CPU

core = ov.Core()

compiled_model = core.compile_model(ov_model, 'CPU')

# استنتاج مدل روی داده‌های تصادفی

output = compiled_model({0: example.numpy()})

مدل TensorFlow

import numpy as np

import openvino as ov

import tensorflow as tf

# بارگذاری مدل TensorFlow در حافظه

model = tf.keras.applications.MobileNetV2(weights='imagenet')

# تبدیل مدل به مدل OpenVINO

ov_model = ov.convert_model(model)

# کامپایل مدل برای دستگاه CPU

core = ov.Core()

compiled_model = core.compile_model(ov_model, 'CPU')

# استنتاج مدل روی داده‌های تصادفی

data = np.random.rand(1, 224, 224, 3)

output = compiled_model({0: data})

OpenVINO از دستگاه‌های CPU، GPU و NPU پشتیبانی می‌کند و با مدل‌های فریم‌ورک‌های PyTorch، TensorFlow، ONNX، TensorFlow Lite، PaddlePaddle و JAX/Flax کار می‌کند. این ابزار شامل APIهایی در C++، Python، C، NodeJS است و GenAI API را برای خط‌لوله‌های مدل بهینه‌شده و عملکرد بهتر ارائه می‌دهد.

با نصب OpenVINO GenAI شروع کنید و برای بررسی قابلیت‌های هوش مصنوعی مولد با استفاده از OpenVINO، به راهنمای دقیق آن مراجعه کنید.

یاد بگیرید چگونه LLMها و GenAI را با نمونه‌های موجود در مخزن OpenVINO™ GenAI اجرا کنید. GenAI را در عمل با نوت‌بوک‌های Jupyter ببینید: چت‌بات مبتنی بر LLM و خط‌لوله دستورپذیری LLM.

مستندات کاربری حاوی اطلاعات دقیقی درباره OpenVINO است و شما را از مرحله نصب تا بهینه‌سازی و استقرار مدل‌ها برای برنامه‌های هوش مصنوعی راهنمایی می‌کند.

مستندات توسعه‌دهنده بر معماری OpenVINO تمرکز دارد و فرآیندهای ساخت و مشارکت را شرح می‌دهد.

- چارچوب فشرده‌سازی شبکه عصبی (NNCF) - تکنیک‌های پیشرفته بهینه‌سازی مدل شامل کوانتیزاسیون و پراکندگی (sparsity).

- مخزن GenAI و توکنایزرهای OpenVINO - منابع و ابزارهایی برای توسعه و بهینه‌سازی برنامه‌های هوش مصنوعی مولد.

- سرور مدل OpenVINO™ (OVMS) - راهکاری مقیاس‌پذیر و با کارایی بالا برای سرویس‌دهی به مدل‌های بهینه‌شده برای معماری‌های Intel.

- Intel® Geti™ - ابزاری تعاملی برای حاشیه‌نویسی ویدیو و تصویر جهت استفاده در بینایی ماشین.

- 🤗Optimum Intel - دریافت و استفاده از مدل‌هایی که از OpenVINO در APIهای Hugging Face بهره می‌برند.

- Torch.compile - استفاده از OpenVINO برای برنامه‌های بومی پایتون از طریق کامپایل JIT کد به کرنل‌های بهینه‌شده.

- ExecuTorch - استفاده از ExecuTorch همراه با OpenVINO برای بهینه‌سازی و اجرای کارآمد مدل‌های هوش مصنوعی.

- استنتاج و سرویس‌دهی LLMهای OpenVINO با vLLM - بهبود سرویس‌دهی سریع و آسان مدل در vLLM با استفاده از بک‌اند OpenVINO.

- ارائه‌دهنده اجرای OpenVINO برای ONNX Runtime - استفاده از OpenVINO به عنوان بک‌اند در کنار کدهای فعلی ONNX Runtime.

- LLMWare - ساخت یکپارچه برنامه‌های هوش مصنوعی سازمانی، گردش‌کارهای عاملی، خط‌لوله‌های RAG، موارد استفاده چندوجهی و موارد دیگر، با استفاده از بیش از ۱۰۰ مدل زبانی کوچک (SLM) آماده استنتاج و بهینه‌شده با OpenVINO.

- LlamaIndex - ساخت برنامه‌های GenAI با تقویت زمینه (context-augmented) با استفاده از چارچوب LlamaIndex و بهبود عملکرد زمان اجرا با OpenVINO.

- LangChain - ادغام OpenVINO با چارچوب LangChain برای بهبود عملکرد زمان اجرا در برنامه‌های GenAI.

- Keras 3 - یک چارچوب یادگیری عمیق چند-بک‌اند است. کاربران می‌توانند استنتاج مدل را با استفاده از Keras API به بک‌اند OpenVINO تغییر دهند.

مخزن Awesome OpenVINO را بررسی کنید تا مجموعه‌ای از پروژه‌های هوش مصنوعی ساخته‌شده توسط جامعه بر پایه OpenVINO را کشف کنید!
