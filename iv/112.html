PcapAnalyzer: عیب‌یابی شبکه در چند ثانیه

Hacker News · 2026-11-22

خطاهای شبکه را در چند ثانیه، نه چند ساعت، پیدا کنید. یک فایل capture با فرمت .pcap یا .pcapng (و همچنین gzip) را بارگذاری کنید تا PcapAnalyzer به شما بگوید چه چیزی دچار مشکل شده، دلیل آن چیست و گام بعدی برای بررسی چیست. این ابزار روی سیستم خودتان اجرا می‌شود، بنابراین فایل‌های capture هرگز از شبکه شما خارج نمی‌شوند. رایگان و متن‌باز (Apache 2.0). وضعیت: بتا.

- امتحان کردن بدون نیاز به نصب: https://pcap-analyzer-seven.vercel.app/#demo

- دانلود: https://sebaandrada6.gumroad.com/l/hspgx (رایگان) یا کلون کردن این مخزن.

- ۲۷ آشکارساز که روی هر capture اجرا می‌شوند و هر کدام دارای سطح اهمیت و گام بعدی هستند:

- TCP: مسدودسازی توسط فایروال (SYN→RST)، بازنشانی‌ها (Retransmissions)، تکرار ACKها، گم شدن و به‌هم‌ریختگی ترتیب بسته‌ها، پنجره‌های صفر و کامل، ریست شدن پس از دست‌دادن (Handshake)، و دست‌دادن‌های کند.

- مسیر (Path): حفره‌های سیاه PMTUD، مقدار MSS پایین، تکه‌تکه شدن IP (Fragmentation)، خطاهای ICMP، و حلقه‌های مسیریابی.

- سرویس‌های نام و آدرس: DNSهای بی‌پاسخ یا کند، SERVFAIL، انفجار NXDOMAIN، خطاهای DHCP NAK / DECLINE / عدم پاسخ، IPهای تکراری، و طوفان‌های ARP.

- برنامه‌ها: پاسخ‌های HTTP 4xx / 5xx و پاسخ‌های کند، هشدارهای TLS، و SSL 3.0 / TLS 1.0 / 1.1.

- تونل‌ها: IPsec (IKE و ESP)، WireGuard، OpenVPN، GRE، L2TP و Teredo که یک‌طرفه هستند، به دست‌دادن پاسخ نمی‌دهند یا مدام در حال بازنشانی هستند.

- امنیت: اسکن و جاروب پورت‌ها، ورودهای متنی ساده (FTP, POP3, IMAP, SMTP AUTH, HTTP Basic؛ اعتبارنامه‌ها هرگز ذخیره یا نمایش داده نمی‌شوند)، Telnet / SMBv1 / SNMP v1-v2c، جعل ARP، و قطعات IP هم‌پوشانی‌شده.

- اولویت با کیفیت capture است. این ابزار زمانی که خودِ capture محدودکننده نتیجه باشد، هشدار می‌دهد: فریم‌های تکراری توسط پورت mirror، ترافیک دیده‌شده فقط در یک جهت، بسته‌های ناقص، و اتصالاتی که هنگام شروع capture از قبل باز بوده‌اند.

- نماهای مشابه Wireshark: لیست بسته‌ها با فیلترهای نمایش واقعی Wireshark روی کل capture، رنگ‌بندی، خروجی CSV، اطلاعات تخصصی، جداول HTTP / DNS / DHCP / TLS، زمان‌های پاسخ و نمودار جریان (Flow diagram) برای هر مکالمه.

- بررسی با هوش مصنوعی (اختیاری): یک هوش مصنوعی با استفاده از ابزارها (فیلترهای واقعی، جزئیات جریان، آمار) capture را بررسی کرده و به بسته‌هایی که پشت هر ادعا هستند استناد می‌کند. سپس می‌توانید سوالات تکمیلی بپرسید. این قابلیت از کلید API شخصی Anthropic شما استفاده می‌کند؛ بدون آن، یک حالت دمو، کل جریان را با متنی که از تحلیل تولید شده، بدون هزینه اجرا می‌کند.

- گزارش PDF، رابط کاربری به زبان‌های اسپانیایی و انگلیسی، تم روشن و تیره.

شما به Docker و Docker Compose نیاز دارید. در ویندوز، اسکریپت را از Git Bash یا WSL اجرا کنید.

git clone https://github.com/sebaandrada-cell/PcapAnalyzer.git

cd PcapAnalyzer

./start.sh

این اسکریپت یک توکن دسترسی تصادفی ایجاد می‌کند (که یک بار نمایش داده شده و در فایل .env ذخیره می‌شود) و برنامه را اجرا می‌کند. پس از پایان بیلد، آدرس http://localhost:8080 را باز کنید، توکن را در فیلد "API token" (بالا سمت راست) وارد کنید و یک capture بارگذاری کنید، یا روی "Try the sample capture" کلیک کنید. برنامه فقط روی 127.0.0.1 گوش می‌دهد. آن را بدون یک پروکسی معکوس احراز هویت‌شده در شبکه قرار ندهید: API می‌تواند از حساب هوش مصنوعی شما استفاده کند.

فایل QUICKSTART.md شامل جزئیات، تنظیمات هوش مصنوعی و عیب‌یابی است.

شما به Python 3.9+، Node 20+ و tshark (نصب‌شده همراه با Wireshark) نیاز دارید.

cd backend

python3 -m venv .venv

.venv/bin/pip install -r requirements-dev.txt

export API_TOKENS="$(openssl rand -hex 32)"

.venv/bin/uvicorn app.main:app --reload

cd frontend

npm install

npm run dev

آدرس http://localhost:5173 را باز کرده و همان توکن را وارد کنید. اگر tshark در PATH شما نیست، TSHARK_PATH را روی فایل اجرایی تنظیم کنید.

- capture روی سیستم شما تحلیل می‌شود. در حین بررسی هوش مصنوعی، فایل به‌صورت رمزگذاری‌شده نگهداری می‌شود (۶۰ دقیقه عدم فعالیت، یا تا زمانی که دکمه "Delete capture now" را بزنید) و سپس حذف می‌شود.

- هوش مصنوعی اختیاری است. این ابزار فقط آنچه را که ابزارهایش برمی‌گردانند می‌بیند (متادیتای بسته؛ محتوای بسته فقط در صورتی که برای آن نشست فعالش کنید)، و هرگز فایل pcap را نمی‌بیند.

- بدون تله‌متری و بدون نیاز به حساب کاربری برای نسخه خود-میزبانی (self-hosted).

cd backend && .venv/bin/python -m pytest -q # نیاز به tshark دارد

cd frontend && npm test

PcapAnalyzer در مرحله بتا است. این ابزار با نمونه‌های مصنوعی و captureهای عمومی تست شده است و مفیدترین بازخورد، captureای است که در آن مشکلی نادیده گرفته شده یا مشکلی گزارش شده که واقعی نیست. لطفاً یک issue در https://github.com/sebaandrada-cell/PcapAnalyzer/issues باز کنید و مورد را شرح دهید. captureهایی که حاوی اعتبارنامه‌های واقعی یا داده‌های مشتری هستند را پیوست نکنید؛ ابتدا آن‌ها را ناشناس‌سازی کنید یا الگو را شرح دهید.

مرجع فنی (طرح JSON، آستانه‌های آشکارساز، محدودیت‌ها، خطاهای API) در فایل README.es.md به زبان اسپانیایی موجود است.
