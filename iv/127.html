کل برنامه را با Rust بازنویسی نکنید. آن ۵ درصدی که کند است را بازنویسی کنید.

Hacker News · 2026-11-22

بازنویسی کل یک اپلیکیشن با Rust ماه‌ها زمان می‌برد، زمان کامپایل را به دقیقه می‌رساند و گیگابایت‌ها فضای target/ اشغال می‌کند. به هر حال، بخش عمده زمان اجرا در چند تابع خاص خلاصه می‌شود.

ابزار fast-anything آن توابع را پیدا می‌کند، از ایجنت کدنویسی شما می‌خواهد که فقط همان‌ها را به Rust پورت کند، اثبات می‌کند که پورت انجام‌شده در فراخوانی‌های واقعیِ ثبت‌شده نتایج یکسانی می‌دهد و سپس آن را جایگزین می‌کند. تنها با یک دستور و کاملاً قابل بازگشت.

npm i -g @el4cteo/fast-anything # یا: cargo install fast-anything

پورت‌ها با زنجیره ابزار Rust شما (rustup) کامپایل می‌شوند.

fast-anything go --agent claude -- python app.py # یا: -- node app.ts / ruby app.rb / java App.java / mvn exec:java / gradle run / go run . / php app.php / clang -O2 main.c

یا مرحله‌به‌مرحله پیش بروید:

پارامتر --agent از claude، codex یا هر دستوری که یک پرامپت را از stdin بخواند پشتیبانی می‌کند. بدون آن، فایل TASK.md را به هر ابزاری که استفاده می‌کنید بدهید.

آن پورت درست به نظر می‌رسید اما به جای کاراکترها، بایت‌ها را مقایسه می‌کرد. ۱۴۸ مورد از ۵۰۰ فراخوانی واقعی این خطا را شناسایی کرد. علاوه بر فراخوانی‌های ثبت‌شده، fast-anything موارد اضافی را استخراج کرده و به نسخه اصلی اجازه می‌دهد به آن‌ها پاسخ دهد: موارد خاص (NaN، ±infinity، -0.0، صفر و ±1، متن‌های غیر ASCII، ورودی‌های خالی و تا ۱۶ برابر بزرگ‌تر) و ورودی‌های کوچک‌شده (اسلایس‌های بسیار کوچک و تصادفی). تا زمانی که تمام موارد مطابقت نداشته باشند، هیچ‌چیز فعال نمی‌شود: مقادیر یکسان (اعداد اعشاری با دقت 1e-9)، و خطاهای مشابه در جایی که نسخه اصلی خطا می‌دهد. پورتی که درست باشد اما در هر فراخوانی کندتر از نسخه اصلی عمل کند (چون هزینه فراخوانی به Rust بیشتر از کار ذخیره‌شده است) نیز فعال نمی‌شود. با تنظیم FAST_ANYTHING_DISABLE=1، همیشه نسخه اصلی اجرا می‌شود.

اجراهای واقعی روی i5-10500 و Windows 11 (برای C و C++: یک رانر ۴ هسته‌ای GitHub Actions Linux) انجام شده است. می‌توانید آن‌ها را از پوشه examples/ بازتولید کنید.

ابزار fast-anything بیرونی‌ترین حلقه‌ای که بتواند را پورت می‌کند، نه تابع کوچکی که درون آن فراخوانی می‌شود؛ بنابراین اپلیکیشن به جای میلیون‌ها بار، تنها یک بار وارد Rust می‌شود. پورت کردن فقط تابع داخلی levenshtein منجر به بهبود ۳۵ برابری و ۱.۹ برابری شد.

- زمان کامپایل: هر پورت یک crate تک‌تابعی است. ثانیه‌ها، نه دقیقه‌ها.

- کش: هر پورت از یک .fast/target مشترک استفاده می‌کند. هر زمان که خواستید آن را حذف کنید.

- ریسک: کد شما همان‌طور که هست باقی می‌ماند. Rust به صورت انتخابی (opt-in) برای هر تابع و با بررسی رفتار واقعی اعمال می‌شود.

- پلاگین Claude Code: دستور /plugin marketplace add EL4CTEO/fast-anything و سپس /plugin install fast-anything@fast-anything و /fast-anything:fast python app.py را اجرا کنید.

- سرور MCP (برای Claude Code، Codex، Cursor و غیره) که در فایل باینری تعبیه شده است: claude mcp add fast-anything -- fast-anything mcp . شامل ۸ ابزار: fast_scan، fast_port، fast_verify، fast_enable، fast_disable، fast_bench، fast_report، fast_status.

- مهارت: بخش skills/fast-anything به هر ایجنتی نحوه کار با حلقه را آموزش می‌دهد.

این ابزار توابع سطح بالا و قطعی (deterministic) که داده‌های ساده (اعداد، رشته‌ها، لیست‌ها، دیکشنری‌ها، آرایه‌های تایپ‌شده و غیره) را می‌پذیرند پورت می‌کند؛ این شامل توابع موجود در اسکریپت اصلی شما نیز می‌شود، زمانی که کد اصلی آن زیر if __name__ == "__main__": (یا if __FILE__ == $0، یا if (import.meta.main) / if (require.main === module)) قرار دارد. در Python این به معنای توابع سطح ماژول و @staticmethods است؛ در Java، C# و PHP به معنای متدهای استاتیک (و توابع در PHP)؛ در Go توابع ساده؛ و در C و C++ توابع آزاد (free functions) و متدهای استاتیک است. دستور scan توضیح می‌دهد که چرا سایر موارد هنوز قابل انتقال نیستند.

با استفاده از Intel oneAPI در ویندوز، fast-anything را از پوسته‌ای (shell) اجرا کنید که setvars.bat در آن اجرا شده باشد (این فایل لینکر را تنظیم می‌کند). هسته‌های SYCL روی دستگاه اجرا می‌شوند و پورت نمی‌شوند؛ با استفاده از -fsycl، فقط توابع میزبان (host functions) پروفایل و پورت می‌شوند.

زبان‌های Ruby، Java، Go، PHP، C، C++ و C# نیازی به هدر، بایندینگ یا ابزارهای اضافی ندارند: پورت یک کتابخانه ساده Rust با یک نقطه ورود C است که JSON می‌گیرد و برمی‌گرداند، و fast-anything فراخوانی‌های ثبت‌شده را مستقیماً روی آن بازپخش می‌کند. هر زبانی که بتواند C را فراخوانی کند، می‌تواند از این پل استفاده کند.
