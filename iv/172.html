نصب و پیکربندی Grafana

Hacker News Feed · 2026-11-25

```bash

sudo apt-get install -y adduser libfontconfig1 musl

wget https://dl.grafana.com/grafana-enterprise/release/13.3.2/grafana-enterprise_13.3.2_44555861735_linux_amd64.deb

sudo dpkg -i grafana-enterprise_13.3.2_44555861735_linux_amd64.deb

```

راهنمای نصب Ubuntu / Debian را مطالعه کنید. ما همچنین یک مخزن APT ارائه می‌دهیم.

```bash

sudo yum install -y https://dl.grafana.com/grafana-enterprise/release/13.3.2/grafana-enterprise_13.3.2_44555861735_linux_amd64.rpm

```

راهنمای نصب Red Hat و Fedora را مطالعه کنید. ما همچنین یک مخزن YUM ارائه می‌دهیم.

```bash

wget https://dl.grafana.com/grafana-enterprise/release/13.3.2/grafana-enterprise_13.3.2_44555861735_linux_amd64.rpm

sudo rpm -Uvh grafana-enterprise_13.3.2_44555861735_linux_amd64.rpm

```

راهنمای نصب OpenSUSE و SUSE را مطالعه کنید. ما همچنین یک مخزن YUM / zypper ارائه می‌دهیم.

بک‌اند Grafana دارای تعدادی گزینه‌ی پیکربندی است که در فایل تنظیمات آن (که معمولاً در سیستم‌های لینوکسی در مسیر /etc/grafana/grafana.ini قرار دارد) تعریف شده‌اند.

در این فایل پیکربندی، می‌توانید مواردی مانند رمز عبور پیش‌فرض مدیر، پورت HTTP، پایگاه داده Grafana (شامل SQLite، MySQL، Postgres)، گزینه‌های احراز هویت (Google، GitHub، LDAP، auth proxy) و بسیاری از تنظیمات دیگر را تغییر دهید.

سرور Grafana خود را راه‌اندازی کنید. با کاربر مدیر خود (به‌صورت پیش‌فرض admin/admin) وارد شوید. منوی کناری را باز کنید (روی آیکون Grafana در منوی بالا کلیک کنید)، به بخش Data Sources بروید و منبع داده خود را اضافه کنید.
