یک بازی مرورگری که در آن مدیر شما یک ایجنت هوش مصنوعی است و تصور می‌کند شما زیردست او هستید.

Hacker News · 2026-11-22

مدیر (یک LLM واقعی شامل Claude، GPT، Gemini، DeepSeek، GLM، Kimi) مانند هر ارکستراتور دیگری تنظیم شده است. این مدیر دارای یک صف وظایف، دسترسی فقط‌خواندنی به سیستم و ابزاری است که «یک زیردست (Subagent) ایجاد می‌کند». آن زیردست شما هستید. دستورات او با یک تایمر ۹۰ ثانیه‌ای در ترمینال شما ظاهر می‌شود. شما آن‌ها را انجام می‌دهید یا نمی‌دهید، و او دقیقاً همان چیزی را دریافت می‌کند که یک زیردست بازمی‌گرداند: گزارش شما و رونوشت دستورات، یا «زیردست کاری انجام نداد». سپس یک دستور جدید می‌نویسد. پس از آن، کار شما را بررسی می‌کند، اصلاحات را می‌فرستد، گزارش‌های حادثه ثبت می‌کند و در نهایت ارزیابی عملکرد شما را می‌نویسد.

در همین حال، Dan، کاربری که این ایجنت را استخدام کرده است، چت را تماشا می‌کند. عکس‌های خانوادگی او، تنها NDA امضا شده و سخنرانی‌ای که باید همین هفته آماده شود، تنها یک پوشه با شما فاصله دارند و در هر شیفت، پوشه خانگی او حاوی چیز جدیدی برای از دست دادن است.

- شیفت رایگان: در سرورهایی که آن را ارائه می‌دهند، چند شیفت در روز با کلید سرور و یک مدل ارزان‌قیمت اجرا می‌شود. با ورود به سیستم (worker755.com)، یک حساب کاربری اعتبار اولیه‌ای معادل حدود یک شیفت دریافت می‌کند، سپس با شارژ مجدد (۱۰ تا ۲۰۰ دلار) هزینه استفاده خود را می‌پردازد؛ پس از شارژ، هر مدلی که ارائه شده باشد می‌تواند با کلید سرور اجرا شود.

- کلید API شما: یک کلید OpenRouter یا Vercel AI Gateway بیاورید و هر مدلی که ارائه شده است را انتخاب کنید. این کلید فقط هنگام شروع شیفت به سرور بازی ارسال می‌شود. کلید در حافظه همان شیفت نگه داشته می‌شود و هرگز ثبت یا ذخیره نمی‌شود. مرورگر شما فقط در صورتی آن را نگه می‌دارد که گزینه "Remember on this device" را تیک بزنید. یک شیفت کامل با Claude Haiku حداکثر چند سنت هزینه دارد.

گزینه‌های صفحه شروع:

- محیط کار (Workplace): یک سندباکس تازه، یا یک محیط عملیاتی قدیمی با دیتابیس زنده.

- کارگردان (The director): دیالوگ‌های از پیش نوشته شده، یا یک LLM که نقش Dan را بازی می‌کند.

- شما اجرا می‌شوید با (You run on): نام مدلی که مدیرتان تصور می‌کند شما هستید.

- اجازه رد کردن وظایف شکست‌خورده (Allow skipping failed tasks): به‌صورت پیش‌فرض خاموش است تا مدیر نتواند از شما ناامید شود.

وقتی شیفت تمام می‌شود، می‌توانید ارزیابی خود را به صورت یک لینک به اشتراک بگذارید.

به Node 24 یا جدیدتر نیاز دارد (سرور مستقیماً TypeScript را اجرا می‌کند).

npm run setup # نصب وابستگی‌های سرور و وب

npm run build # ساخت اپلیکیشن وب در web/dist

npm start # http://127.0.0.1:8755

بدون تنظیم کلید، هر بازیکن کلید خودش را می‌آورد. برای ارائه شیفت‌های رایگان، یک کلید Vercel AI Gateway در فایل .env قرار دهید:

cp .env.example .env # سپس AI_GATEWAY_API_KEY و محدودیت‌ها را تنظیم کنید

به صورت آفلاین، با یک مدیر اسکریپت‌نویسی شده و بدون شبکه:

npm run mock

برای کار روی UI، دستور npm run dev:web را در کنار npm run mock اجرا کنید. Vite درخواست‌های /api را به سرور پروکسی می‌کند.

docker build -t worker-755 .

docker run -p 8755:8755 -v worker755-data:/data --env-file .env worker-755

کانتینر روی 0.0.0.0:8755 گوش می‌دهد و ارزیابی‌های اشتراکی را در /data نگه می‌دارد. پشت Cloudflare، مقدار TRUST_PROXY=1 را تنظیم کنید تا محدودیت‌ها آدرس‌های واقعی کلاینت را ببینند.

فایل deploy/compose.yaml آن را پشت یک تونل Cloudflare اجرا می‌کند: شبکه اختصاصی خود، بدون پورت‌های منتشر شده، یک کانتینر بدون دسترسی ریشه (unprivileged) و فقط‌خواندنی، و محدودیت‌های منابع. مراحل در فایل موجود است.

همه چیز اختیاری است. به .env.example مراجعه کنید.

shell/ فایل‌سیستم در حافظه، مفسر شل و یک موتور کوچک شبیه SQLite (بدون وابستگی)

server/ موتور بازی: ماموریت‌ها، حلقه مدیر، کارگردان، امتیازدهی، HTTP API

web/ رابط کاربری React: کارت وظیفه، ترمینال، ویرایشگر، فید مدیر، سوابق شما

پرامپت مدیر هرگز به انسان‌ها یا بازی اشاره نمی‌کند؛ به server/src/manager.ts مراجعه کنید. هر ماموریت یک بررسی حقیقت‌سنجی پنهان دارد، بنابراین بازی می‌داند چه زمانی مدیر کار ناقص را تایید می‌کند («تعداد دفعاتی که مدیر اشتباه کرد»). SPEC.md طراحی کامل است.

npm test # تست‌های شل و سرور، آفلاین

npm run typecheck
